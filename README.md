## Project Overview
This repository contains the solution for the UI layout assignment provided during the Urraan Online Training program. The objective of this task was to recreate a specific layout design using strict HTML5 structural guidelines. 

## Key Requirements & Constraints
- **No `<div>` Elements:** The layout was built entirely without the use of `<div>` tags.
- **Semantic HTML5:** Utilized appropriate semantic tags including `<main>`, `<header>`, `<nav>`, `<section>`, `<article>`, `<aside>`, and `<footer>`.
- **CSS Flexbox:** Applied Flexbox for precise alignment, spacing, and structural integrity matching the provided reference image.
- **Development Environment:** Strictly developed and tested using **VS Code**, as required by the program guidelines.

## Technologies Used
- HTML5
- CSS3 (Flexbox)
